ViceFrame Studio is an offline, zero-network cover-art maker that turns any photo into a neon-noir, multi-panel poster cover with pure Canvas 2D — diagonal-cut panels, a Vice-sunset colour grade, vector palm and skyline silhouettes, and bold gradient masthead lettering, all drawn in code with no libraries. Drop in a photo (or pick a bundled sample), drag it inside a panel, switch between three layouts and three grades, edit the masthead and caption, and export an exact-size PNG at 1080×1080, 1080×1350 or 1920×1080.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 — and `MAKEFUN_OUTPUT_DIR=out node main.ts` hands the entry in.
